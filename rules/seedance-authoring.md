## 五、分镜提示词规则与参考媒体

### 5.1 规则优先级

顺序：用户本次提供的全局提示词规则和明确锁定项 → 原文/已确认长文及改编边界 → 启用且明确选择的专业参数（限其对应范围）→ 当前主参考的适用方法 → 一般创作默认值。

专业项和 Skill 都不能解除“不编造媒体标签”“不篡改台词”“原文保护”等约束。参考案例只提供方法和风格，不作为本片事实。

把本章规则保存为版本化的项目内规则文档，并由所有 Seedance 分镜生成、重写、引用绑定和导出共用，不能只写进 UI 提示。

### 5.2 提示词架构

每镜按以下顺序组织，按内容取舍，不为凑结构输出空块：

【场景语境】
【活跃参考】
【场地映射】
【首帧与空间调度】
【格式模式】
【光学镜头】
【摄影机机位】
【动作时间轴】
【物理法则】
【灯光】
【音频】
【正向约束】

【输出设置】仅在生成 UI 未选择或对叙事至关重要时出现，例如受控多镜头、常速/慢动作。始终保留的“无字幕”及独立旁白时的“无音乐”按下面音频规则内联表达。

独立【负向约束】块默认省略；已知高概率失败用局部“无 X”短语约束，不堆叠通用负向词。

“场景语境”写本镜可执行的场景信息，不泄漏内部镜号、数据库 ID、“见上一镜”等外部上下文。动作时间轴写因果顺序，不写挂钟式秒段。

### 5.3 活跃参考和草稿状态

未生成/绑定媒体时，使用资产名称和明确身份描述写草稿，不生成虚假的 `<<<image_N>>>` 等标签。

实际绑定媒体后，以本镜的参考清单确定性分配 image、video、audio 各自的序号，仅列本镜真正使用的 `<<<image_N>>>`、`<<<video_N>>>`、`<<<audio_N>>>`。不得沿用前一镜过期标签。

每个角色图片标签跟年龄、状态和关键可见标识符；场景、道具、声音使用适合各自类型的描述锚点。身份描述必须匹配实际参考，不能把“年龄”硬套给场景或音频。

当前 Owl 文本 AI 接口不能自动证明图片与文字 100% 一致。绑定后并排显示图片/播放器和锚点，让用户核对；确认绑定内容和锚点摘要后标记可用于出片。替换媒体、改锚点或改绑定顺序使确认失效。

案例参考视频用于方法展示，不会自动成为每镜的活跃视频参考，也不能声称 AI 已观看分析它。

### 5.4 空间调度

使用可测量、可观察的物理语言：

| 避免 | 改为 |
|---|---|
| 附近、周围、旁边 | 在 1 米以内、紧贴接触、距离主体左侧 0.5 米 |
| 某处、不远处 | 正好站在标志牌正下方、背靠指定墙面 |
| 靠着车 | 一只手撑在烤焦的引擎盖上 |

身体朝向和视线分别写，例如“躯干朝向门口；眼睛锁定另一角色”“头转向窗户；背对摄影机”。明确角色间距离、摄影机所在一侧、道具所属及左右手。

### 5.5 光学镜头视觉特征库

| 视觉角度预设 | 必须表达的视觉特征 |
|---|---|
| 47° 标准 | 自然透视、无明显畸变、面部身体比例自然、背景可读但不夸张。 |
| 84° 经典广角 | 自然的透视延伸、前景人物贴近且存在感强、环境延伸到画面边缘、建筑直线无鱼眼弯曲。 |
| 107° 畸变校正广角 | 极近前景巨大、直线挺拔、边到边深景深、微妙色差、无圆形暗角。 |
| 29° 短中焦肖像 | 通过焦距延伸实现紧凑构图而非身体贴近、主体锐利、背景柔和散景、主体与环境分离。 |
| 18° 经典长焦 | 背景空间压缩、极浅焦平面突出关键面部、前后景柔化、远距离观察感。 |
| 8° 超长焦观察 | 极端压平背景、模糊前景遮挡画面下方 30%–45%、远距离观察或野生动物纪录片感。 |

长焦至少写 4 个可观察物理特征短语，广角至少 3 个。以上作为用户定义的视觉预设，不擅自将角度换算为固定毫米焦距。

### 5.6 动作运动栈

动作按：摄影机运动/剪辑 → 主体动作与面部节拍 → 空间调度/环境变化 → 音频。

身体部位带动作幅度与速度，多节拍按因果顺序，先主后次。不写“0–3s 做 A，3–6s 做 B”等秒段。内部时长、TTS 测时和剪辑时间仍可保存，但不将它们机械拼进 Seedance 提示词。

### 5.7 音频与对白

包装语法按需使用：音乐 `(…)`；音效 `<…>`；对话为台词正文，非项目主语言时前置语言说明；画面文字包装为 `【…】`，但本项目默认始终无字幕，不能因模板示例而自动添加字幕。

- 独立旁白全文只写在声音脚本，不在视频提示词重复；该镜提示词内联“无音乐”。
- 所有镜头内联“无字幕”。
- 对话镜头明确：说话角色嘴唇仅在念台词时移动；其他角色静听；不说话时嘴唇闭合。
- 仅使用风格化剧本中已确定的台词原文，无多余词、无即兴；角色名用于说明说话者，不作为念出的文本，除非台词本身包含该名字。
- 需要台词前后留白时，每句前后至少 1 秒静默；需要立即开口时，在主镜头开始后的 0.3 秒内开口。二者作为按剧情选用的表演要求，不同时无条件附加。

对白、旁白、环境音分别保存，现有配音/测时接口改为读取该结构，不再只扫描 action.dialogue 导致顶层台词丢失。角色音色及参考音频通过稳定角色 ID 关联，兼容旧按角色名配置的数据。

### 5.8 灯光、物理、密度和风格

灯光是高优先级约束。逆光镜头必须明确：主体在摄影机与更亮背景之间；摄影机位于主体阴影侧；面部深陷阴影，轮廓光、边缘光、眼神光或环境反光揭示细节；严禁正面主光和平淡均匀曝光。

用户反馈逆光变平时，增强为：按逆光背景曝光，允许面部陷入死黑，以剪影和轮廓支撑画面。普通场景不强制逆光。

动作必须有物理因果，按需使用：

- 行走：脚后跟着地、重量转移、髋部重心偏移、脚趾蹬地。
- 奔跑：真实接触力、提膝、对侧手臂摆动、躯干前倾、不规律步幅。
- 武器：手臂承重、手腕随质量改变、刀刃惯性。
- 液体：附着、滴落、涂抹、积聚；水滴抛物线；黏稠度与方向。

身份、空间、首帧、视线、距离、道具状态、光学特征、灯光、物理和对白需要精确；通用审美、参考图已明确的服装、群众和非活跃道具可以精简。

写完可执行控制后才追加紧凑风格锚点，例如自然光手持、受控剪影、亲密广角、Kodak Vision3 500T 颗粒。允许采用用户给出的卢贝斯基、迪金斯、卡隆、雷弗恩等参考语言，但不能与实际机位和灯光冲突，不堆砌冗长风格名字。

### 5.9 长度与质量检查

项目提供 Seedance 2.5 / 2.0 提示词规格选择，新项目默认 2.5。按用户指定限制执行：2.5 ≤ 4500 字符，2.0 ≤ 2300 字符。字符数按 Unicode 码点计算，前后端一致；加入媒体标签后再次校验，不能直接截断台词或控制句。

结构校验和 AI 自检共同检查：实际引用、首帧可见角色、站位/朝向/视线、可测距离、机位侧、镜头特征数量、逆光约束、道具左右手、动作物理性、对白原文、无秒段、无字幕、旁白不重复、长度限制、无内部场景编号泄漏。

格式、引用、长度及原句一致性由代码校验；画面物理和风格冲突由 AI 自检并保留结果，不能假称代码已完全判断视觉正确。失败时针对问题修正，有限重试后保留候选和失败原因。

Seedance 提示词作为中文创作主稿；本地 H3 出片仍经过已有英文转写适配，不将 Seedance 标签直接提交到 H3，也不以修改 Seedance 原稿的方式适配 H3。
